# 高科選課助手

高科大選課頁的瀏覽器擴充功能。它把課程名額、釘選清單和常用查詢整理在同一個頁面，讓你查課時少切換頁面，也能快速回到正在關注的課程。

![高科選課助手](apps/extension/logo.svg)

## 特色

- 在課程列表顯示已選人數、限修人數與目前狀態。
- 顯示「可選」、「已滿」或「名額未知」三種狀態。
- 依學期保存釘選課程，釘選課程會出現在列表上方。
- 即使課程暫時不在目前的查詢結果中，也能從上方清單查看並更新名額。
- 釘選課程在列表中以橘色標記，方便快速辨識。
- 保存每學期的上課時間篩選。
- 提供博雅教育中心與體育課程快捷查詢；查詢體育課程時會保留目前年級。
- 支援高科大不同分流的選課頁面，例如 `aais1`、`aais3`、`aais4`、`aais5` 與 `aaisx`。

## 使用範圍

擴充功能只在高科大加選課程頁執行，使用目前分頁的登入狀態查詢名額，並把釘選與時間篩選保存到瀏覽器本機。它不會自動登入，也不會在背景替使用者送出加選操作；是否操作校方頁面上的按鈕，由使用者自行決定。

## 安裝

### Chrome

1. 開啟 `chrome://extensions`。
2. 開啟右上角的「開發人員模式」。
3. 點擊「載入未封裝項目」。
4. 選取本專案的 `apps/extension` 資料夾。
5. 開啟高科大加選課程頁並重新整理。

### Microsoft Edge

1. 開啟 `edge://extensions`。
2. 開啟左側或右上角的「開發人員模式」。
3. 點擊「載入解壓縮的擴充功能」。
4. 選取本專案的 `apps/extension` 資料夾。
5. 開啟高科大加選課程頁並重新整理。

## 使用方式

1. 先用一般方式登入高科大選課系統，進入「加選課程」頁。
2. 查詢課程後，在課程列查看名額與狀態。
3. 點擊課程名稱旁的「釘選」，將課程加入本學期清單。
4. 從頁面上方的釘選卡片查看課號、課名與名額；點擊卡片可回到課程列。
5. 開啟上課時間選擇器後，可使用「套用上次選課篩選」還原同一學期保存的條件。
6. 查詢通識或體育課程時，使用頁面上的快捷按鈕，再執行校方原本的查詢。

## 名額狀態

工具會讀取校方課程資料中的「已選上人數」與「限修人數」：

| 狀態 | 判斷方式 |
| --- | --- |
| 可選 | 已選上人數小於限修人數 |
| 已滿 | 已選上人數大於或等於限修人數 |
| 名額未知 | 校方回應缺少必要數字，或目前頁面尚未完成載入 |

遇到「名額未知」時，請先確認仍在高科大加選課程頁、登入狀態有效，再重新整理頁面。校方服務忙碌或回應格式調整時，也可能暫時無法判讀名額。

## 權限與資料

擴充功能使用的權限只有：

- `storage`：在瀏覽器本機保存釘選課程與上課時間篩選。
- 高科大加選課程頁的網站權限：讀取課程列表、查詢名額並更新頁面上的顯示。

資料不會送到開發者或其他第三方服務。擴充功能不保存帳號、密碼或 Cookie，也沒有背景服務在頁面關閉後執行工作。

## 專案結構

```text
apps/extension/
├── manifest.json       # Manifest V3 設定與權限
├── content.js          # 課程列表、釘選與篩選功能
├── page-hook.js        # 在校方頁面查詢名額
├── styles.css          # 頁面樣式
├── logo.svg            # 橘色品牌圖像
└── icons/              # 16、32、48、128 像素圖示
```

這個擴充功能不需要建置工具。修改程式後，在瀏覽器的擴充功能管理頁按「重新載入」，再重新整理校方頁面即可。

## 開發檢查

```bash
node --check apps/extension/content.js
node --check apps/extension/page-hook.js
node -e 'JSON.parse(require("fs").readFileSync("apps/extension/manifest.json"))'
```

## 封裝

在專案根目錄執行：

```bash
cd apps/extension
zip -r ../../nkust-course-assistant-extension.zip \
  manifest.json content.js page-hook.js logo.svg icons styles.css README.md
```

封裝後，請確認 ZIP 解開後最上層直接包含 `manifest.json`，不要再多包一層 `apps/extension` 資料夾。

## 注意事項

本工具不是高科大官方服務。課程名額、選課時間與頁面功能以校方公告及選課系統實際顯示為準。
